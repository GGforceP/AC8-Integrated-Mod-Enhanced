# AC8 Integrated Mod Enhanced v2.6.1

适配 Steam 1.01.002（Build 26002268）。仅限离线单人。

- 启动器左侧安装范围下方新增 **启用 HOTAS 武器数值**。默认关闭，保存后在下次离线启动生效。
- 采用 Modern Missile Mod 1.1.0 HOTAS 档的玩家武器锁定距离、备弹倍率与伤害。可与三个安装范围搭配，重叠字段采用 HOTAS 值。
- 备弹按机型、改装等级和挂载方式计算。MPBM 采用玩家弹体上的数值，共用爆炸伤害区由游戏结算。

在 Build 26002268 的苏-35 离线任务中，完整强化与 HOTAS 同时通过回读。开场和正式关卡都核验了 130 项武器字段与 7,681 项备弹字段。一级苏-35 机型表的 6AAM 单挂由 30 增至 60，双挂由 18 增至 36。

关闭游戏和启动器，运行 **AC8-Integrated-Setup-v2.6.1.exe** 即可覆盖安装。已安装 Enhanced 的用户也可以在启动器右上角检查更新。[安装与更新说明](APP.md) · [原始 HOTAS 预设](https://www.nexusmods.com/acecombat8wingsoftheve/mods/154?tab=description)
